# 기존 예측 모델 최종 정리

작성 기준: 2026-09-11  
정리 목적: 교수님 피드백을 반영해 새 예측 방식으로 전환하기 전, 지금까지 직접 만든 모델과 결과를 포트폴리오용 핵심 기록으로 남긴다.

## 결론

지금까지의 프로젝트는 하나의 단일 모델이 아니라, 국내 주식 섹터의 다음 거래일 흐름을 예측하기 위해 여러 예측층을 조합한 실험형 섹터 로테이션 시스템이었다.

최종적으로 확인한 점은 다음과 같다.

| 판단 | 내용 |
| --- | --- |
| 기존 모델의 성격 | 가격, 수급, 뉴스, FOMO, 장중 흐름, 리스크 게이트를 결합한 다층 예측 시스템 |
| 가장 중요한 성과 | 데이터 수집부터 예측, 검증, 문제 해결 기록까지 end-to-end 구조를 직접 구축 |
| 가장 큰 한계 | 변수와 보조 모델이 많아져 예측 근거가 무거워지고, 방향 예측 성능이 충분히 안정되지 않음 |
| 최종 운영 판단 | 기존 모델은 실험 결과로 보관하고, 새 메인 방향은 모멘텀 중심의 단순한 상승/하락 예측 모델로 전환 |
| 포트폴리오 관점 | 완성형 수익 모델보다, 예측 시스템을 설계하고 실패 원인을 검증하며 개선한 과정이 핵심 성과 |

## 기존 메인 모델

기존 메인 모델은 `sector_return_primary_v3_multi_output` 정책을 따르는 섹터 수익률 예측 모델이다.

| 항목 | 내용 |
| --- | --- |
| 모델명 | `sector_return_primary_v3_multi_output` |
| 주요 산출물 | `sector_model_v2_metrics.json`, `tomorrow_sector_prediction.csv` |
| 학습 기준 | 2026-08-20 |
| 데이터 기간 | 2023-05-02 ~ 2026-08-19 |
| 학습 데이터 | 7,236행 |
| 테스트 데이터 | 2,400행 |
| 선택 피처 수 | 134개 |
| 주요 타깃 | 다음 거래일 섹터 수익률, 상승 여부, 의미 있는 상승 여부, 초과수익 여부 |
| 입력 데이터 | 가격, 거래량, 거래대금, 수급, 환율, DART, pykrx, KRX, 시장 방향성 변수 |

이 모델은 다음 거래일에 각 섹터가 상승할 가능성과 예상 수익률을 동시에 추정하려는 구조였다. 단순 상승/하락만 보는 것이 아니라, 수익률 중심값과 예상 구간까지 같이 만들었다.

## 모델 구성 요소

| 구성 요소 | 역할 | 최종 판단 |
| --- | --- | --- |
| 상승 확률 모델 | 다음 거래일 섹터 상승 가능성 추정 | 방향 예측의 기본층으로 사용 |
| 예상 수익률 모델 | 다음 거래일 수익률 중심값과 구간 추정 | 구간 커버율은 의미 있었으나 중심값 오차가 남음 |
| 섹터 랭킹 모델 V3~V5 | 섹터 간 상대 순위 산출 | Top3 후보 선별용으로 사용 |
| FOMO Overlay | 뉴스/검색 관심도 급증 반영 | 효과가 불안정해 최종 비중을 크게 낮춤 |
| 장중 반등 모델 | 당일 장중 흐름에서 반등 후보 탐지 | 보조 신호로만 유지 |
| 리스크 게이트 | 급락장, 과열, 데이터 품질 문제에서 행동 판단 보수화 | 예측값을 막는 장치가 아니라 위험 해석층으로 재정리 필요 |
| Shadow 모델 | 메인 모델 교체 전 후보 모델 성능 누적 비교 | 일부 후보가 개선을 보였지만 최종 교체는 보류 |

## 최종 성능 요약

`prediction_accuracy_summary.json` 기준 누적 검증 결과는 다음과 같다.

| 지표 | 값 | 해석 |
| --- | ---: | --- |
| 평가 예측 수 | 540건 | 2026-05-12 ~ 2026-08-10 기준 |
| 전체 방향 정확도 | 42.6% | 단순 상승/하락 방향 예측은 기준선 이상으로 안정화되지 못함 |
| 상대 초과수익 양수 비율 | 46.1% | 시장 대비 강한 섹터 선별도 아직 불안정 |
| Top1이 실제 Top3에 포함된 비율 | 28.9% | 최상위 하나를 맞히는 능력은 제한적 |
| Top3 겹침률 | 31.9% | 후보군 선별은 일부 의미가 있으나 충분히 강하지 않음 |
| 평균 RankIC | 0.031 | 순위 상관은 약한 양수 |
| NDCG@3 | 0.594 | 상위권 정렬 품질은 보조 지표로만 활용 가능 |
| 예상 수익률 구간 커버율 | 71.8% | 구간 예측은 방향 예측보다 상대적으로 안정적 |
| 예상 수익률 중심 절대오차 | 약 2.99%p | 중심 수익률은 보수적으로 해석해야 함 |

해석하면, 기존 모델은 “실제 투자 진입 신호”로 쓰기에는 아직 부족하지만, 섹터 후보를 만들고 어떤 변수가 효과가 없었는지 검증하는 실험 시스템으로는 의미가 있었다.

## Shadow 모델과 교체 판단

기존 프로젝트에서는 새 모델이 하루 잘 맞았다고 바로 교체하지 않고, Shadow 모델로 일정 기간 성능을 비교했다.

| 항목 | 결과 |
| --- | --- |
| Shadow 비교 목적 | 메인 모델 교체 전 후보 모델의 성능을 누적 검증 |
| 최종 가중치 판단 | 라이브 가중치 변경 없음 |
| 교체 보류 이유 | 개선폭이 기준치보다 작고, RankIC 악화 또는 표본 부족 문제가 남음 |
| 추천 블렌드 | `common_total_fomo_light`가 일부 개선을 보였으나 shadow-only 유지 |
| 최소 필요 개선폭 | 0.02 |
| 실제 개선폭 | 약 0.0027 |

`shadow_rank_v6`는 최근 일부 구간에서 메인보다 나은 성과를 보였다.

| 비교 | 메인 | Shadow V6 |
| --- | ---: | ---: |
| Top3 겹침률 | 29.2% | 37.5% |
| RankIC | -0.045 | 0.131 |
| Top3-Bottom3 spread | -0.080 | 0.813 |

다만 평가일이 충분하지 않고, 운영 게이트가 최종 승격을 승인하지 않았기 때문에 실전 메인 모델로 교체하지 않았다.

## FOMO와 뉴스 지표의 최종 판단

FOMO 지표는 프로젝트의 독자적인 시도였지만, 최종 검증에서는 라이브 모델의 핵심 변수로 두기 어렵다고 판단했다.

| 항목 | 결과 |
| --- | --- |
| 최종 FOMO 라이브 비중 | 약 0.0048 |
| 검증 결과 | FOMO가 항상 상승으로 이어지지 않음 |
| 최종 판단 | 메인 모델의 중심 변수가 아니라 보조 해석 지표로 유지 |

초기에는 뉴스와 관심도 급증이 섹터 상승을 설명할 수 있다고 보았지만, 실제 검증에서는 과열과 추격 신호가 섞였다. 따라서 FOMO는 새 모델에서는 핵심 입력이 아니라, 사후 해석 또는 관심도 설명 변수로 낮춘다.

## 장중 반등 모델

장중 반등 모델은 장중 흐름을 학습해 반등 후보를 잡기 위한 별도 실험이었다.

| 항목 | 값 |
| --- | ---: |
| 학습 기준 | 2026-09-01 |
| 학습 데이터 | 2,016행 |
| 테스트 데이터 | 404행 |
| 양성 비율 | 약 10.6% |
| 정확도 | 89.9% |
| ROC-AUC | 0.703 |
| Precision / Recall | 0.0 / 0.0 |

정확도는 높아 보이지만 양성 표본이 적어 실제 반등을 적극적으로 잡아내지는 못했다. 따라서 이 모델은 메인 예측이 아니라 장중 관찰 보조 모델로만 유지한다.

## 기존 방식에서 얻은 교훈

| 배운 점 | 새 방식에 반영할 내용 |
| --- | --- |
| 변수가 많다고 성능이 좋아지지는 않음 | 예측 시점에 확정된 핵심 모멘텀 변수 위주로 축소 |
| 뉴스/FOMO는 방향 신호가 아니라 관심도 신호에 가까움 | 메인 입력보다 보조 설명 변수로 사용 |
| 수익률 구간은 방향보다 안정적일 수 있음 | 방향 예측을 우선 만들고, 이후 보조 산출물로 구간 예측 |
| Shadow 모델 비교는 운영 안정성에 도움이 됨 | 새 모델에서도 후보 모델은 바로 교체하지 않고 비교판 유지 |
| 리스크 게이트가 너무 강하면 예측 자체를 가릴 수 있음 | 새 구조에서는 예측과 위험 해석을 분리 |
| 장중 모델은 표본 불균형에 취약함 | 장중 반등은 별도 보조 기능으로 분리 |

## 새 예측 방식으로의 전환

교수님 피드백을 반영해 앞으로의 메인 모델은 다음 방향으로 재정의한다.

| 기존 방식 | 전환 후 방식 |
| --- | --- |
| 여러 데이터와 보조 모델을 결합한 복합 예측 시스템 | 모멘텀 중심의 단순하고 검증 가능한 상승/하락 예측 모델 |
| 수익률, 랭킹, FOMO, 게이트를 동시에 통합 | 먼저 다음 거래일 상승/하락 방향 예측에 집중 |
| 추세형 지표와 복합 점수 다수 사용 | 원값보다 변화량, 거리, 모멘텀, 과열/침체 지표 중심 사용 |
| 예측과 행동 판단이 복잡하게 결합 | 예측 결과와 위험 해석을 분리 |
| 성능 해석이 어려움 | 50% 기준선, 55~60% 의미 있는 예측력 기준으로 단순 검증 |

최종적으로 기존 모델은 포트폴리오에서 “직접 만든 실험형 예측 시스템과 그 한계”로 정리하고, 새 모델은 “예측 가능한 시점의 모멘텀 지표로 다음 거래일 상승/하락을 검증하는 모델”로 전환한다.

## 포트폴리오용 한 문장

이전 모델은 국내 주식 섹터 예측을 위해 가격, 수급, 뉴스, FOMO, 장중 흐름, 리스크 게이트를 결합한 실험형 예측 시스템이었고, 누적 검증 결과 방향 예측 성능은 충분히 안정되지 않았지만 데이터 수집부터 모델 검증, Shadow 비교, 운영 게이트까지 구축한 경험을 바탕으로 더 단순하고 검증 가능한 모멘텀 기반 예측 모델로 전환하게 되었다.
